To Markdown 1.3.1 merampingkan paket desktop tanpa mengurangi fitur aplikasi.

Installer turun dari **180,8 MiB menjadi 140,5 MiB** (hemat **22,3%**). Ukuran file hasil ekstraksi turun dari **643,2 MiB menjadi 435,1 MiB**.

- Source map debugging, bundle Mermaid alternatif dan demo library tidak lagi ikut installer.
- Bahasa bawaan Chromium: Indonesia dan Inggris; teks dokumen Unicode tetap didukung.
- Konversi enam format, Markdown editor, diagram, rumus, simpan file dan updater tetap tersedia.

Pengguna 1.3.0 dapat memilih Bantuan → Periksa pembaruan. Simpan dokumen sebelum pemasangan. Pengguna 1.2.0 perlu mengunduh installer secara manual.

Pemeriksaan terbatas: enam format berhasil dikonversi melalui worker paket baru, 106 modul Mermaid tersedia, kode runtime aplikasi yang dipertahankan identik dengan 1.3.0. QA penuh dan uji instalasi/upgrade tidak dijalankan. Installer masih belum ditandatangani sertifikat penerbit.
